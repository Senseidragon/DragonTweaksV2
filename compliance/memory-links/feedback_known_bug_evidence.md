# Unsupported External-Cause Claims

Source: [[none]]

Claims like “known bug,” “mod conflict,” “JVM issue,” “NeoForge issue,” or “environment problem” require evidence.

Required evidence:

- citation, issue, log source, or local evidence
- matching symptom or stack trace
- affected version match
- explanation for why the known-good version works while the current version fails

Unsupported external-cause claims are invalid and must not redirect diagnosis.
