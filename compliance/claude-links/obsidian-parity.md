# Obsidian Parity

The Obsidian vault at `obsidian-docs/` is the human-readable counterpart to project memory.

## Purpose

Dragon must be able to inspect and reason about project state without relying solely on Claude.

## When required

When intentionally creating, promoting, or updating a `type: project` memory entry, create or update the corresponding Obsidian document and link it from the appropriate map-of-content document.

## Limits

Do not make unrelated Obsidian edits as a side effect of ordinary coding, debugging, or lookup tasks.

Do not create Obsidian parity for raw, rejected, tentative, or unvalidated memory unless the procedure explicitly requires a human-review note.

## Verification

Report the memory file and matching Obsidian file together when parity is updated.
