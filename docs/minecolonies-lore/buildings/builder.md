The [[Builder's Hut]] is the first building that must be constructed before any other. Without it, the Builder cannot be assigned to any work orders. When placing the [[Builder's Hut]], consider its position relative to the rest of the planned colony — a central location minimizes the distance the Builder has to walk between their hut and each build site.

To start, craft the [[Builder's Hut]] block, place it with the Scepter of Gold, and issue a build order through the hut. The Builder will first construct their own hut, requesting materials as they go. Outstanding material requests appear in the Resource Scroll or the Required Resources tab; anything still missing is shown in red.

A critical constraint: the Builder can only construct or upgrade any other building to a level equal to their own hut's level. Upgrading the Builder's Hut is always the prerequisite for upgrading anything else. The Builder finishes one project completely before starting another, so build order priority matters. If a work order is cancelled mid-build and then reissued, the Builder will resume from where construction left off. Any blocks removed during construction are kept in the Builder's inventory and deposited back at the [[Builder's Hut]] at the end of the job.
