The [[Fletcher's Hut]] is where the Fletcher will craft arrows and items that use string or wool, such as bows, fishing rods, and paintings. For the Fletcher to work, they must receive a request from another worker and have the necessary materials. The [[Fletcher's Hut]] must also have been taught the crafting recipes for all the items you want the Fletcher to be able to craft.

> **Note:** Upgrading the [[Fletcher's Hut]] lets you teach it more recipes. So:

| Building Level | Number of Recipes |
| -------------- | ----------------- |
| 1              | 10                |
| 2              | 20                |
| 3              | 40                |
| 4              | 80                |
| 5              | 160               |
