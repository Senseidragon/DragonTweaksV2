# Web Memory Ingestion Pipeline

Source: [[none]]

Legacy Minecraft wiki-derived approved entries are suspect unless they passed the raw → cleaned → advisor → validation process.

Required pipeline:

1. raw deep scrape
2. cleaned reference
3. short advisor artifact
4. optional flavor derived only from advisor
5. metadata
6. candidate
7. validation
8. promotion
9. reindex/flush

Raw and cleaned files are evidence/reference only. Advisor-grade files are the default retrieval material for practical gameplay questions.

Flavor is derived from advisor material only, not directly from raw or cleaned scrape data.
