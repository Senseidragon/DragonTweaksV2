# MineColonies API Integration

MineColonies is a `compileOnly` dependency — present at compile time, optional at runtime.

Live colony state (citizen counts, building levels, resource needs) is surfaced to the advisor via tool calls. The advisor can describe what's happening in the player's colony based on real game state rather than guessing.

Local MineColonies source is available as a cloned baseline for API reference. Do not use `javap` stubs as an authoritative source — use the cloned source or `docs/api/`.
