The [[Crusher's Hut]] is where the Crusher will take items and crush them into other blocks. The defaults are: 

| Starting Item | Created Item                 |
| ------------- | ---------------------------- |
| Bone          | Bonemeal                     |
| Bone Block    | Bonemeal                     |
| Cobblestone   | Gravel (chance to get flint) |
| Clay          | Clay Ball                    |
| Gravel        | Sand                         |
| Sand          | Clay                         |

> **Note:** By default the Crusher their ratio is 2:1, but by unlocking the Gildedhammer research in the [[University]] you can make them work on a 1:1 ratio.
