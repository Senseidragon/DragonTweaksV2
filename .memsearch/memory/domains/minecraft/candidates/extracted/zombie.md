*   The zombie is a playable DLC character in the crossover fighting game _[Super Smash Bros. Ultimate](https://minecraft.wiki/w/Super_Smash_Bros._Ultimate "Super Smash Bros. Ultimate")
    _ as an alternate costume for Steve.
